speedtest (Node.js)

Консольный скрипт: делает 10 последовательных запросов к адресу, каждый раз дожидается полного ответа, затем печатает среднее время, общий объём и скорость.

Требования

Node.js 18 или новее (проверить: node --version). Внешние пакеты не нужны, npm install не требуется.

Запуск
node speedtest.js https://example.com/big-image.jpg
node speedtest.js https://example.com/big-image.jpg -n 5 -t 60

Параметры: -n — число запросов (по умолчанию 10), -t — таймаут одного запроса в секундах (по умолчанию 30).

Единицы измерения
Объём — мегабайты (МБ), 1 МБ = 1 000 000 байт.
Время — секунды.
Скорость — МБ/с; дополнительно Мбит/с (1 МБ/с = 8 Мбит/с).
Как считается
Время запроса — от отправки запроса до получения последнего байта тела (включая установку соединения).
Среднее время = суммарное время / число успешных запросов.
Скорость = общий объём / суммарное время (не среднее из скоростей).
Считаются байты тела ответа, получаемые из сети; заголовки не учитываются.
Неудачные запросы (сеть, таймаут, HTTP-ошибка) в статистику не входят; код выхода при этом 1.
